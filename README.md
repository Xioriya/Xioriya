## /shipping

**[kerf](https://github.com/Xioriya/kerf)** — a fast, sharp TUI coding agent.
Guile Scheme, no build step, talks to any OpenAI-compatible endpoint, keeps the
terminal as the interface. Built for speed, clarity, and local models.

```text
▰ kerf 0.2                                                      start · direct
╭──────────────────────╮   options
│ ▸ Session            │   enter changes · s saves · r reloads
```
